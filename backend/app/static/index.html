Supported project workflow
  • CSV websites remain read-only reference data.
  • CAPTCHA types are identified and reported.
  • Only authorized local or staging URLs can be automated.
  • Official provider test keys can be verified.
  • Real CAPTCHA challenges require manual completion or a test environment with CAPTCHA disabled.
